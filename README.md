# 3D 打印入门课

一门从零开始的 3D 打印（FDM）交互课程。每一章有一个可以拖着转、用滑块拨着玩的 3D 演示，拨一拨就知道某个设置到底改变了什么。

在线阅读：https://realruian.github.io/3d-print-101/

## 目前的内容

| 章 | 主题 | 可以拨弄的东西 |
|---|---|---|
| 1 | 认识机器 | 一台双喷嘴打印机的结构示意，点部件看说明，演示打印时的动作 |
| 2 | 从模型到实物 | 模型、切片、打印三个阶段，逐层查看和播放 |
| 3 | 层高 | 层高滑块，看弧面上的台阶和耗时怎么变；附切片软件工艺面板的对照 |
| 5 | 墙和填充 | 剖开的方块：墙层数、填充密度、填充图案，估算用料 |
| 6 | 摆放和支撑 | 翻转零件看哪里悬空，显示支撑并估算多用的料 |

第 4 章和第 7 到 12 章（走线和接缝、第一层、材料、多色和双喷嘴、为打印而设计、故障图鉴、日常维护）还在制作中。

课程里的例子以一台 0.4 mm 双喷嘴、带四槽料盒的全封闭打印机和 PLA 耗材为准，切片软件以 Bambu Studio 中文版为例。

## 本地使用

整门课就是一个文件：`index.html`。下载后双击，用浏览器打开即可。

页面里的 3D 演示会从公共 CDN 加载 three.js，所以需要联网；断网时文字照常显示，3D 部分会提示没能加载。

## 奖杯模型

`奖杯/` 文件夹里是一个用 OpenSCAD 做的参数化镂空奖杯，正面是自绘字形的 INNATE，也是课程里“为打印而设计”的实际例子。

- `innate_trophy.scad`：主模型，尺寸、笔画粗细、文字都是参数
- `innate_glyphs.scad`：自绘的等粗线条字形库
- `innate_trophy.stl`：按打印姿态（背面朝下躺平）导出的成品，不需要支撑
- 其余 `.scad` 和 `.png` 是设计过程中的早期版本和预览图

用 0.4 mm 喷嘴、0.20 mm 层高、PLA 打印，约 2 小时 47 分钟、126 克。

`.scad` 文件通过 macOS 的系统路径引用了 Impact 和 DIN Condensed 字体，只用于底座上的小字和早期版本；在其他系统上需要改成本机的字体路径。
